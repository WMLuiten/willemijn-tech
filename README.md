# willemijn.tech

Personal website for [willemijn.tech](https://willemijn.tech), built with Astro.

## Development

Requires Node.js 22.12 or newer and npm.

```sh
npm install
npm run dev
```

The site currently contains three routes:

- `/`
- `/about/`
- `/contact/`

## Checks

```sh
npm run lint
npm run format:check
npm run check
npm run build
```
